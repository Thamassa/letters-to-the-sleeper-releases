# Letters to the Sleeper

Oyunun resmi Windows sürümleri ve otomatik güncelleme paketleri.

[Son Windows sürümünü indir](https://github.com/Thamassa/letters-to-the-sleeper-releases/releases/latest)

Windows zip dosyasını indir, bir klasöre çıkar ve `LettersToTheSleeper.exe` dosyasını aç.
Oyunun kayıtları güncellemeden etkilenmez. v1.0.37 öncesi bir exe kullanıyorsan yeni zip dosyasını bir kez indir;
bundan sonraki oyun içi güncellemeler bu depodan alınır.

Her sürümde `Dreamwalker.pck` oyun içi güncelleme paketidir; tek başına çalıştırılmaz.
`latest.json` güncel sürümü, indirme adresini, paket boyutunu ve SHA-256 doğrulamasını içerir.

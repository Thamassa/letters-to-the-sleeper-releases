# Letters To The Sleeper

Oyunun resmi Windows sürümleri ve otomatik güncelleme paketleri.

[Son Windows sürümünü indir](https://github.com/Thamassa/letters-to-the-sleeper-releases/releases/latest)

Windows zip dosyasını indir, bir klasöre çıkar ve `LettersToTheSleeper.exe` dosyasını aç.
İstersen aynı sürümdeki `LettersToTheSleeper.exe` dosyasını tek başına da indirebilirsin.

v1.0.43 ile proje, kayıt ve dağıtım adları standartlaştırıldı. Yeni Windows paketini bir kez indir;
önceki sürümlerin kayıtları ilk açılışta otomatik kopyalanır. Yeni kayıt klasörü `%APPDATA%\LettersToTheSleeper\`.
Oyun içi güncelleme kullanılıyorsa mevcut ilerleme aynı profilde korunur.

`LettersToTheSleeper.pck` oyun içi güncelleme paketidir; tek başına çalıştırılmaz.
`latest.json` güncel sürümü, indirme adresini, paket boyutunu ve SHA-256 doğrulamasını içerir.
